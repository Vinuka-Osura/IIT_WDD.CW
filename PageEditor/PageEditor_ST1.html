🛠️ Technical Description

1️⃣ Volunteer Page

The Volunteer Page was designed using a **flexbox layout** to structure volunteer opportunities in a grid format. The key elements used include:

  • section - To logically group volunteer opportunities.
  • div.card - Each opportunity is displayed as a card.
  • img - Used for volunteer icons and images.
  • CSS Grid & Flexbox - Ensures responsiveness and alignment.

2️⃣ User Reviews & Ratings

The reviews section includes an **overall rating** and individual user reviews in styled cards. Key implementation details:

  • div.review-card - Each review is placed inside a card with a border.
  • CSS Hover Effects - To highlight reviews when hovered.
  • Star Ratings - Implemented using ★ Unicode stars.

3️⃣ Feedback Form

A structured feedback form allows users to submit reviews. It includes:

  • textarea - For user input.
  • button - Styled **Submit** and **Cancel** buttons.
  • CSS Button Hover Effects - Changes color when hovered.

⚡ Challenges & Lessons Learned

One major challenge was ensuring the **volunteer cards** were responsive. Initially, images were not aligning properly, but using **CSS Grid** and **media queries**, I ensured they adapted to different screen sizes.

♿ Accessibility

Accessibility was considered by:

  • Adding **alt text** to images.
  • Using **semantic HTML** for better screen reader support.
  • Ensuring proper **color contrast** for readability.

✅ Compliance

Our website adheres to **Janet regulations** by:

  • Following **HTML5 & CSS3 best practices**.

  • Maintaining **clear navigation and usability**.
