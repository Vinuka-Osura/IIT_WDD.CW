Splash Screen

Technical Description

Structure and content Presentation

  • <h1> : The title of the website is placed within an <h1> tag to indicate its importance as the main heading.
  • <p>: The mission statement and team members are wrapped in <p> tags to ensure they are displayed as distinct text blocks.
  • <button>: A button is included to allow users to manually navigate to the home page in case they do not want to wait for the automatic redirection.

Automatic Redirection

The <meta> refresh tag is used to automatically redirect users to the home page after 4 seconds. This method ensures a seamless transition from the splash screen without requiring user interaction. The following meta tag is implemented in the <head> section of the HTML file:


                                meta http-equiv="refresh" content="4;url=../HomePage/home.html"

Background Image Integration

  • The background property is used to apply a full-screen image to the splash screen, ensuring a visually engaging design.
  • background: url('images/Bookcases.jpg'); :This ensures that the image covers the entire screen while maintaining aspect ratio.
  • A semi-transparent dark overlay (rgba(0,0,0,0.5)) is applied to improve the contrast between the background image and the text, making the content more readable.

Animated Loader

  • A <div class="loader"> element is used to create a spinning animation using CSS keyframes.
  • The animation is achieved using the @keyframes spin rule, which rotates the loader continuously. The animation starts at 0 degrees and smoothly rotates to 360 degrees, creating a spinning effect:
Sample code:


                                @keyframes spin {
                                    0% { transform: rotate(0deg); }
                                    100% { transform: rotate(360deg); }
                                }

  • This ensures that the content is vertically and horizontally centered, making it visually balanced.

                                    align-items: center;
                                    justify-content: center;
                                    height: 100vh;
  • Adds space on the sides, preventing the text from being too wide and ensuring readability. 
    
                                    padding: 0 10%;
  • Enables continuous rotation for the loader.

Accessibility

  • The page follows a semantic HTML structure, using <h1> for the main title and <p> for descriptive text.
    This ensures that screen readers can navigate and interpret content correctly, improving accessibility for visually impaired users.
  • A dark overlay (background: rgba(0, 0, 0, 0.5)) is applied over the background image.
    This improves the contrast between the text and background, making the content readable for users with low vision.
  • The line-height property is used to improve text readability:
    This ensures that text is not too cramped, making it easier to read, especially for users with cognitive impairments. 
    
                            .mission {
                                line-height: 1.6;
                            }
  • The "Go to Website" button is a standard <button> element allowing keyboard navigation using "Tab" key and activation using "Enter key".
  • The automatic redirection using <meta> tags may cause issues for screen reader users.
    To provide an alternative, a manual "Go to Website" button is also included so users can navigate at their own pace.

Volunteer Page

Technical Description

Main structure and content Presentation

The main structure of the page is built using common HTML tags and styled with CSS.

  • <!DOCTYPE html>: Declares the document as HTML5.
  • <head>: Contains metadata, such as the character set (<meta charset="UTF-8">), viewport settings for responsiveness (<meta name="viewport" content="width=device-width, initial-scale=1.0">), and links to external stylesheets (<link rel="stylesheet" href="...">).
  • <body>: Contains all visible content on the page.
  • <header>: Holds the navigation bar placeholder (<div id="header-placeholder"></div>)integrated from the global.js file.
  • <section>: Used to group related content, such as volunteer cards, reviews, and feedback.

Scrollable Information Section

This section includes volunteer cards, buttons, and a dropdown for sorting and filtering.

Volunteer Cards:
  • Each card is created using a <div> with the class "card".
  • For each card:
    • Title: <h2> for the card title.
    • Description: <p> for a brief description of the volunteer opportunity.
    • What is needed list: <ul >and <li> for listing what is needed (e.g., "Teachers to teach Maths, Science, and English").
    • Register Now Button: <button> for registration, styled with a blue background and hover effect.
    • Date Circle: <div class="date-circle"> to display the event date and location.
    • Images: <img> for visual appeal, positioned absolutely within the card.
Dropdown for Sorting:
  • Created using a <select> element with <option> tags for sorting options (e.g., "Most Popular," "Newest").
  • Styled with padding, border, and hover effects for interactivity.

User Ratings and Reviews Section

This section displays overall ratings and individual reviews from volunteers.

Overall Rating Summary:
  • Created using a <div> with the class "overall-rating".
  • This displays:
    • A rating score (<p class="rating-score">).
    • Star icons (<p class="rating">).
    • A summary text (<p class="rating-summary">).
Individual Reviews:
  • Each review is a <div> with the class review-card.
  • Each card contains:
    • A rating (<p class="review-rating">).
    • Review text (<p class="review-text">).
    • A "See More" link (<a href="#" class="see-more">).
    • Metadata (e.g., reviewer name and date).

Feedback Form

This section allows users to submit feedback about their volunteering experience.

Form Elements:
  • Star Rating Input: Created using radio buttons (<input type="radio">) styled as stars.
  • Feedback Text Area: A <textarea> for users to write their reviews.
  • Buttons: <button> elements for submitting or canceling feedback.

Key CSS Techniques and Justification

  • CSS Grid (display: grid;):
    Used for the volunteer cards and individual reviews to create a responsive, organized layout. Grid allows for precise control over the placement of elements, making it ideal for creating multi-column layouts.
  • Flexbox (display: flex;):
    Used for aligning the overall rating and reviews side by side. Flexbox is perfect for creating flexible, one-dimensional layouts and aligning items within a container.
  • Media Queries (@media):
    Used to adjust the layout for smaller screens (e.g., changing the cards to a single-column layout). Media queries ensure the page is responsive and accessible on all devices.

Accessibility

In the volunteer.html page, several techniques were used to address accessibility.

  • Semantic HTML tags were used to provide meaningful structure to the page, making it easier for screen readers and assistive technologies to interpret the content.
  • ARIA roles and attributes were used to enhance accessibility for dynamic content and interactive elements.
  • The page is designed to be fully navigable using a keyboard, ensuring that users who cannot use a mouse can still interact with the content.
  • All images include descriptive alt attributes, providing text alternatives for screen readers and users who cannot see the images.
